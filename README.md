# BackInTime - Negros Island Heritage and Cultural Tourism Platform

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-black?style=for-the-badge&logo=vercel)](https://backintime-heritage.vercel.app/)

> **Live Platform:** [https://backintime-heritage.vercel.app/](https://backintime-heritage.vercel.app/)

BackInTime is an interactive cultural heritage and tourism web platform documenting the history, ancestral architecture, and cultural landmarks of Negros Island, Philippines.

---

## Key Features

- **Landmark Showcase**: Detailed profiles of historical structures, ancestral houses, and centuries-old landmarks across Negros Island.
- **Categorized Discovery**: Navigation indexed by epoch, architectural style, and municipality.
- **Responsive Design**: Fast, lightweight interface built with Tailwind CSS and semantic markup.
- **Interactive Timelines**: Historical narrative sections documenting island heritage across key eras.

---

## Technology Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

---

## Running Locally

```bash
# Clone the repository
git clone https://github.com/condeadriankeith/BackInTime.git
cd BackInTime

# Launch in browser
start index.html
```
