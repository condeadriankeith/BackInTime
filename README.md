## 🌟 Overview
**BackInTime** is an interactive cultural heritage and tourism web platform celebrating the history, ancestral architecture, and cultural landmarks of **Negros Island, Philippines**. Built with responsive web technologies and modern aesthetic design, the platform allows history enthusiasts, tourists, and students to discover heritage spots, virtual tours, and historical timelines.

---

## ✨ Key Features
* 🏛️ **Curated Landmark Explorer:** Detailed showcases of historical landmarks, ancestral houses, and centuries-old churches across Negros Island.
* 🗺️ **Interactive Navigation & Discovery:** Categorized navigation for easy exploration by municipality, epoch, and theme.
* 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile displays with fluid Tailwind CSS typography and layouts.
* 🎨 **Rich Visual Storytelling:** High-resolution imagery, heritage narratives, and cultural insights.
